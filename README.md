# Minecraft-Modpack

Hier liegen die Profil-Dateien für unseren Minecraft-Server (NeoForge). Mit **ModSync** bleibt dein CurseForge-Profil automatisch auf dem Stand des Servers.

## Einrichten (einmalig)

1. **[ModSync.exe herunterladen](https://github.com/lonitys/MinecraftModpack/releases/tag/tool-1.0.0)**. Die Datei liegt unter *Assets*.
2. ModSync starten. Falls Windows warnt: *Weitere Informationen → Trotzdem ausführen*.
3. Auf **„Update holen“** klicken und den Schritten folgen:
   - Die CurseForge App öffnet sich. Dort links *Minecraft* wählen.
   - Oben auf **„Create Custom Profile“** klicken, dann auf **„Import“**.
   - Die Profil-Datei auswählen. ModSync zeigt sie dir im Explorer, und der Pfad liegt schon in der Zwischenablage.
4. Wenn alle Mods geladen sind: **„Einstellungen übernehmen“** klicken. Damit kommen Tastenbelegung, Grafik, Serverliste, Shader usw. ins neue Profil.
5. Das neue Profil in der CurseForge App starten und mit dem Server verbinden.

## Bei Updates

ModSync öffnen → **„Update holen“** → wie oben importieren → danach kannst du alte Profile mit **„Alte Profile löschen“** aufräumen.

Tipp: Unter *Einstellungen* „Beim Windows-Start im Hintergrund nach Updates schauen“ aktivieren. Dann bekommst du eine Windows-Benachrichtigung, sobald es ein neues Pack gibt.

## Was liegt hier?

- **Releases `pack-…`:** die Profil-Dateien (CurseForge-Mod-Liste + `pack.json` mit den Änderungen). Die CurseForge App lädt die Mods selbst von CurseForge.
- **Releases `tool-…`:** neue ModSync-Versionen. ModSync zeigt dir selbst an, wenn es eine neue gibt.
